About this edition

A reading edition of Robert Burton’s The Anatomy of Melancholy, generated from a structured base text with separate layers for translations and notes. This build ({{ profile }} profile, {{ built }}) contains {{ n_units }} text pages.

The text

The base text is Burton’s sixth edition (1651) as edited and modernised by Angus Gowland (Penguin Classics, 2021), taken from the publisher’s EPUB (sha256 {{ source_hash[:16] }}…). Burton’s words, spelling as Gowland gives it, his sidenotes and his headings are kept exactly; corrections appear only as marked corrections with the source’s reading available. Gowland pruned some of Burton’s sidenotes, so the sidenotes here are those of his edition.

Burton cites / Probably / Source
“Burton cites” repeats Burton’s own attribution, which is not proof. “Probably” is a stated guess with its basis. “Source” is used only for a verified match. Unidentified quotations say so.

How machine-produced items are made

Translations and language rulings are produced by a resumable script that calls a model with a fixed, versioned prompt and records the model, prompt version, date and input for every result. Gowland’s translations are never given to the model. The records in this build:

Type and tools

Set in EB Garamond, with Cardo for the apothecary and astrological signs EB Garamond lacks (both SIL Open Font License, subset to the characters used). Latin and Greek are hyphenated at build time with Claudio Beccari’s Latin patterns (MIT licence) and Pyphen’s Greek patterns. The site works offline once loaded.
